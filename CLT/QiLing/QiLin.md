# QiLing



## 基本功能

基于Flutter开发麒麟上位机控制App：
1. 硬件设备管控
   - 与 IJetty 服务端通信，实现 LED/LCD 大屏点屏拼接、接口卡连接关系配置、预置场景（播放 / 一键调用 / 定时切换）操控、RK 板卡 IP 等基础信息配置、瓶组控制等上位机操作；
2. 流媒体推流
   - 基于 FFmpeg_kit_flutter 实现文件推流（RTSP 协议），支持将本机视频文件封装推送至 RK 内网 MediaMTX 或云端 MediaMTX
   - 基于 RTMP+X264 编码实现直播推流（适配 USB 摄像头、监控摄像头等采集设备），非 RTMP 原生支持的 YUV+PCM 源数据先编码为 H.264+AAC 再通过 RTMP 推流
3. 流媒体拉流与预监
   - 通过 Media3 ExoPlayer（支持 RTMP/HLS/RTSP）拉流播放，实时展示 LED/LCD 大屏设备状态、预监板卡音视频流
   - 支持多用户并发访问 RK 板卡本地局域网流媒体资源池，直接拉取 RK 本地发布的 RTSP/RTMP 流完成移动端实时画面预监
4. 卡莱特AI智能语音助手
   - 集成科大讯飞语音SDK，实现语音唤醒、VAD语音活动检测、STT语音转文字、TTS语音合成能力
   - 接入LLM大模型实现语义理解与指令解析，接入VL视觉大模型，支持基于画面风格的模糊场景匹配与切换
     - 支持用户语音输入模糊场景需求（如温和、明亮、科技、温馨等），自动抽取预制场景素材进行VL模型识别匹配，智能推荐并切换最符合的预置场景
   - 通过语音/视觉语义联动控制，实现场景切换、灯光、音量、设备启停等场控设备智能化操控
