# 数据结构与算法分析

> 本篇仅整理与 **流媒体工程** 强相关的数据结构/算法要点，作为通用算法课的补充索引。

---

## 1. 队列（Queue）—— 生产者消费者

直播发送路径上的 **PacketQueue**、播放器内部的 **jitter buffer**，抽象都是 **FIFO 队列**。

- **有界队列**：防止内存无限增长；满时丢帧/丢包策略即 **算法权衡**（低延迟 vs 流畅）。  
- **并发队列**：多生产者单消费者（MPSC）在编码器与发送线程之间常见。

**复杂度**：入队/出队均摊 O(1)。

---

## 2. 优先级队列 / 堆 —— 按 DTS/PTS 排序

部分播放器或封装层需按 **解码时间戳** 排序待解码包，可用 **最小堆**（按 DTS）。

---

## 3. 哈希表 —— 快速索引

- 会话 ID → 推流上下文  
- 文件 ID → HLS 分片路径  

均摊 O(1) 查找。

---

## 4. 滑动窗口 —— 码率估计与拥塞控制（概念）

可用滑动窗口统计 **最近 N 秒** 的发送字节数估算上行码率，用于自适应降级（与操作系统调度配合）。

---
