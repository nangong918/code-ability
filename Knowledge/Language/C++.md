### C++ 关键字

#### 一、基本数据类型

C++基础原生数据类型，用于定义变量的数据存储格式。
包含布尔类型、单字节字符、宽字符、Unicode字符、各类整型、浮点型，void。

|关键字| 占用字节                  | 取值范围/特性详解                                                                           |
|---|-----------------------|-------------------------------------------------------------------------------------|
|bool| 1                     | 布尔类型，true、false                                                                     |
|char| 1                     | `ASCII`单字节字符类型，取值范围 `-128~127`（有符号）或 `0~255`（无符号），用于存储普通字符                          |
|signed char| 1                     | 有符号字符类型，取值范围 `-128 ~ 127`，可存储正负字符对应数值                                               |
|unsigned char| 1                     | 无符号字符类型，取值范围 `0 ~ 255`，仅存储非负字符数值                                                    |
|wchar_t| 2/4（平台相关）| 宽字符类型，用于存储`Unicode`中文、特殊符号，Windows：固定 2 字节 Linux / Android /iOS/macOS：固定 4 字节       |
|char16_t（C++11）| 2                     | 16位`Unicode`字符类型，取值范围 `0 ~ 65535`，适配通用多语种字符存储                                       |
|char32_t（C++11）| 4                     | 32位`Unicode`字符类型，取值范围 `0 ~ 4294967295`，适配高精度字符编码                                    |
|short| 2                     | 短整型，取值范围 `-32768 ~ 32767`，小范围整数存储，节省内存                                              |
|unsigned short| 2                     | 无符号短整型，取值范围 `0 ~ 65535`，仅存储非负短整型数值                                                  |
|int| 4                     | 基础整型，取值范围 `-2147483648 ~ 2147483647`，日常整数运算首选类型                                     |
|unsigned int| 4                     | 无符号整型，取值范围 `0 ~ 4294967295`，适配非负大数存储                                                |
|long| 4/8（平台相关）             | 长整型，拓展整型取值范围，适配较大整数存储；Windows 32 位 / 64 位：4 字节；Linux / Android /iOS/macOS 64 位：8 字节 |
|unsigned long| 4/8（平台相关）             | 无符号长整型，仅存储非负长整型数值，上限高于普通long；同上                                                     |
|long long（C++11）| 8                     | 长长整型，取值范围 `-9223372036854775808 ~ 9223372036854775807`，超大整数运算专用                       |
|unsigned long long（C++11）| 8                     | 无符号长长整型，取值范围 `0 ~ 18446744073709551615`，极致大数非负存储                                      |
|float| 4                     | 单精度浮点型，有效数字`6-7`位，取值约`±3.4e±3`8，基础小数计算使用                                                |
|double| 8                     | 双精度浮点型，有效数字`15`位，取值约`±1.7e±308`，常规高精度小数运算                                               |
|long double| 8/12/16（平台相关）         | 扩展精度浮点型，精度高于double，用于科学计算、极致精度场景；x86/x86_64（Windows/Linux）：8 / 12 / 16 字节都有可能；ARM 架构（Android /iOS）：统一 8 字节（和 double 一样）      |

void func() {}

#### 二、类型修饰符

用于修饰变量、类成员的属性，限定数据的读写特性、符号特性与内存特性。
signed/unsigned 区分数值正负；
const 定义只读常量；
volatile 告知编译器变量值可能被外部修改，禁止优化；
mutable 允许类内常量成员在 const 成员函数中修改。

|关键字|作用详解|
|---|---|
|signed|表示有符号类型，为数值赋予正负属性，默认整型、字符类型均为有符号，可存储正数、负数、0|
|unsigned|表示无符号类型，修饰后变量仅存储非负数，同等字节下数值上限更高，无负数取值|
|const|常量修饰符，定义只读常量，变量/成员初始化后无法修改，保障数据安全性|
|volatile|易变变量修饰，告知编译器变量可能被硬件、多线程等外部修改，禁止编译器优化，强制实时读取内存原值，多用于嵌入式、并发开发|
|mutable|仅用于类成员，允许类内该成员在 const 修饰的常量成员函数、常量对象中正常修改，突破const只读限制|

**实例代码**

```cpp
// 常量：初始化后不能修改
const int MAX_SIZE = 100;

// 无符号类型
unsigned int u_val = 255;

// 有符号类型
signed int s_val = -50;

// 易变变量：禁止编译器优化
volatile int status = 0;

// ====================== const 函数 + mutable 完整示例 ======================
class Test {
public:
    int normal_num = 0;         // 普通变量
    mutable int cache_num = 0;  // mutable 变量（可在const函数中修改）相当于例外的意思

    /**
     * const 成员函数：承诺不修改对象
     * 只读函数，不写。相当于安全函数
     * 面向对象的封装+数据安全；Java没有此类型的方法，只能用final修饰字段
     */
    void show() const {
        // normal_num = 100;   // ❌ 错误！const函数不能修改普通成员
        cache_num = 100;      // ✅ 正确！mutable 变量可以修改
    }
};
```

#### 三、标准类型转换

C++专属四种安全、规范的类型转换方式，替代C语言粗暴强制转换，分类适配不同转换场景，规避类型转换风险。
static_cast 实现常规静态类型转换；
dynamic_cast 用于多态父子类安全转换；
const_cast 专门移除/添加常量属性；
reinterpret_cast 实现内存二进制重解释转换。

|关键字|作用详解|
|---|---|
|static_cast|常规静态类型转换，编译期完成校验，用于数值类型互转、普通父子类转换，适用于所有安全、无风险的类型转换场景|
|dynamic_cast|动态安全转换，运行时校验类型合法性，专门用于多态父子类转换，安全实现向下转型，转换失败返回空指针|
|const_cast|专属属性转换，唯一可以移除、添加变量const、volatile常量属性的转换方式，仅修改修饰属性，不改变变量数据类型|
|reinterpret_cast|内存二进制重解释转换，直接读取内存原始数据，实现指针、整数等非常规类型互转，多用于底层开发、地址操作场景|

**实例代码**

```cpp
// 静态转换
int a = 10;
double b = static_cast<double>(a);

// 常量转换
const int c_num = 20;
int* change_num = const_cast<int*>(&c_num);

// 重解释转换
int* ptr = reinterpret_cast<int*>(0x1000);
```

#### 四、存储与链接属性

控制变量、函数的存储位置、生命周期、作用域及跨文件链接特性。
auto 自动推导变量类型；
register 建议变量存储在寄存器；
static 修饰静态变量/函数，延长生命周期、限定文件作用域；
extern 声明外部全局变量/函数；
explicit 禁止构造函数隐式类型转换；
export 用于导出模板跨文件使用。

|关键字|作用详解|
|---|---|
|auto|自动类型推导关键字，编译器根据变量初始化值自动匹配数据类型，简化复杂类型定义，C++11核心特性|
|register|寄存器变量修饰，建议编译器将高频访问变量存储在CPU寄存器中，提升变量访问效率，减少内存读取开销|
|static|静态修饰符，修饰局部变量可延长生命周期、保留上次数值；修饰全局变量/函数可限定当前文件作用域，禁止跨文件访问|
|extern|外部链接声明，仅声明不定义，用于引用其他源文件的全局变量、函数，实现跨文件代码调用|
|explicit|显式构造函数修饰，禁止类构造函数发生隐式类型转换，避免隐性类型转换带来的逻辑BUG|
|export|模板导出关键字，用于导出模板定义，支持模板跨文件引用与实例化，解决模板跨文件链接失效问题|

**实例代码**

```cpp
auto val = 3.14; // 自动推导为double
register int cnt = 0; // 寄存器变量
static int static_val = 1; // 静态局部变量
extern int g_val; // 声明外部全局变量

class Demo {
public:
    explicit Demo(int a) {} // 禁止隐式转换
};
```


#### 五、流程控制语句

控制程序代码执行逻辑与流程，实现条件判断、循环遍历、分支选择、流程跳转。
是程序逻辑编写的核心关键字，支撑所有业务逻辑流程。

|关键字|作用详解|
|---|---|
|if / else|基础条件判断语句，if匹配条件成立逻辑，else匹配条件不成立逻辑，实现双分支、多分支嵌套逻辑判断|
|for|循环语句，集成初始化、条件判断、步进操作，结构紧凑，适用于已知循环次数的遍历、迭代场景|
|while|前置循环语句，先判断条件、再执行代码，条件不成立则直接不执行循环体，适配未知循环次数场景|
|do|后置循环语句，与while搭配使用，先执行一次循环体，再判断条件，保证代码至少执行一次|
|switch / case / default|多分支选择语句，switch匹配变量值，case对应具体分支逻辑，default处理所有匹配失败的默认场景，替代多段if-else嵌套|
|break|终止跳转语句，用于跳出循环、switch分支，直接终止当前代码块的执行|
|continue|循环跳转语句，终止当前循环迭代，跳过剩余代码，直接进入下一次循环，不终止整体循环|
|goto|无条件跳转语句，可直接跳转到代码标记位置，语法灵活但可读性、维护性差，常规开发不推荐使用|

**实例代码**

```cpp
// 条件判断
bool flag = true;
if (flag) {} else {}

// 循环语句
for (int i = 0; i < 5; i++) {}
int j = 0;
while (j < 3) j++;
do {} while (false);

// 分支语句
int num = 2;
switch (num) {
    case 1: break;
    case 2: break;
    default: break;
}
```

#### 六、异常处理机制

C++标准异常处理体系，用于捕获、抛出、处理程序运行时异常，避免程序直接崩溃，提升代码健壮性。
try 包裹监控代码，
throw 主动抛出异常，
catch 匹配并处理对应异常。

|关键字|作用详解|
|---|---|
|try|异常监控代码块，包裹所有可能出现运行时异常的代码，负责监听异常触发|
|throw|主动抛出异常，可自定义异常信息、异常类型，手动触发异常机制，中断正常代码执行流程|
|catch|异常捕获处理器，精准匹配try块抛出的异常类型，接收异常并执行修复、提示、兜底等处理逻辑|

**实例代码**

```cpp
try {
    int a = 10, b = 0;
    if (b == 0) throw "除数不能为0";
}
catch (const char* err) {
    // 捕获并处理异常
}
```

#### 七、面向对象核心

支撑C++面向对象编程特性，用于定义类、结构体、枚举、共用体；
控制类成员访问权限；定义友元打破访问限制；定义虚函数实现多态特性。

|关键字|作用详解|
|---|---|
|class|类定义关键字，面向对象核心载体，用于封装成员变量、成员函数，支持封装、继承、多态三大特性|
|struct|结构体定义，默认成员为公有权限，主打轻量化数据封装，用于存储一组关联数据|
|union|共用体定义，所有成员共享同一块内存空间，同一时间仅一个成员生效，极致节省内存，多用于底层协议解析|
|enum|枚举定义，自定义整数常量集合，固定取值范围，提升代码规范性与可读性|
|public|公有访问权限，修饰的类成员可在本类、子类、外部任意位置访问，权限等级最高|
|protected|保护访问权限，修饰的成员仅本类、派生类可访问，外部无法访问，适配继承场景的权限管控|
|private|私有访问权限，修饰的成员仅本类内部可访问，子类与外部均无法访问，封装性最强|
|friend|友元关键字，允许指定外部类、外部函数访问当前类的私有、保护成员，打破类的访问权限限制|
|virtual|虚函数修饰，用于父类成员函数，开启运行时多态，支持子类重写函数，实现动态绑定|

**实例代码**

```cpp
enum Color { RED, GREEN, BLUE };
struct Student { int id; };
union Data { int a; char b; };

class Base {
private:
    int private_val; // 私有成员
protected:
    int pro_val; // 保护成员
public:
    virtual void func() {} // 虚函数
    friend class Test; // 友元类
};
```

#### 八、函数工具关键字

辅助函数定义、调用与运算重载。
return 用于函数返回值；
inline 定义内联函数减少调用开销；
operator 实现运算符重载；
sizeof 计算数据类型/变量占用内存字节数；
this 指向当前类对象的指针。

|关键字|作用详解|
|---|---|
|return|函数返回关键字，终止当前函数执行，同时向函数调用方返回指定数值，无返回值函数可仅写return终止函数|
|inline|内联函数修饰，编译期将函数代码直接嵌入调用位置，消除函数调用栈开销，提升高频小函数执行效率|
|operator|运算符重载关键字，自定义标准运算符的运算逻辑，让自定义类支持加减、比较等运算符操作|
|sizeof|内存大小计算关键字，编译期执行，用于获取任意数据类型、变量占用的内存字节数|
|this|类专属指针，指向当前正在调用函数的类实例对象，用于区分成员变量与局部变量、返回当前对象|

**实例代码**

```cpp
inline int add(int a, int b) {
    return a + b;
}

class Calc {
public:
    int operator+(const Calc& other) { return 1; }
    void show() {
        cout << sizeof(int) << endl;
        this->add(1,2);
    }
};
```

#### 九、命名空间与泛型模板

解决命名冲突、支撑泛型编程。
namespace 定义命名空间隔离代码；
using 引入命名空间或类型别名；
template 定义泛型模板；
typename 标识模板中的类型参数。

|关键字|作用详解|
|---|---|
|namespace|命名空间定义，划分独立代码作用域，隔离不同模块的同名变量、函数、类，彻底解决命名冲突问题|
|using|引入关键字，可引入指定命名空间、类型别名，简化代码书写，支持C++11类型别名定义写法|
|template|泛型模板定义，编写通用无类型代码，适配多种数据类型复用，避免重复重载函数、定义类|
|typename|模板类型标识，用于模板参数中，告知编译器当前标识符是数据类型而非变量，规范泛型写法|

**实例代码**

```cpp
namespace MyCode {
    int num = 100;
}
using namespace MyCode;

template<typename T>
T getMax(T a, T b) {
    return a > b ? a : b;
}
```

#### 十、类型别名与类型查询

typedef 用于为已有数据类型自定义别名，简化代码书写；
typeid 用于运行时获取变量、对象的具体类型信息，常用于类型判断与调试；
C++11新增using别名写法，更简洁规范。

|关键字|作用详解|
|---|---|
|typedef|传统类型别名关键字，为已有数据类型自定义新名称，简化长类型、复杂嵌套类型的代码书写|
|using（C++11）|新型类型别名关键字，替代typedef，语法更直观简洁，支持模板别名定义，是现代C++推荐写法|
|typeid|运行时类型查询关键字，可精准获取变量、对象、表达式的真实类型信息，多用于程序调试、类型判断|

**实例代码**

```cpp
typedef int Integer;
using MyInt = int; // C++11 新式别名写法
Integer a = 10;
MyInt b = 20;

// 获取类型名称
cout << typeid(a).name() << endl;
```

#### 十一、动态内存管理

用于堆区动态内存的申请与释放。
new 手动在堆内存分配空间并初始化；
delete 释放 
new 申请的堆内存，避免内存泄漏，分为单个内存与数组内存释放两种场景。

|关键字|作用详解|
|---|---|
|new|堆内存申请关键字，手动在堆区分配内存空间，支持单个变量、数组内存初始化，不受栈内存大小限制，生命周期自主控制|
|delete|堆内存释放关键字，专门用于释放new申请的堆内存，普通delete释放单个变量内存，delete[]释放数组内存，防止内存泄漏|

**实例代码**

```cpp
// 单个内存申请释放
int* p = new int(5);
delete p;

// 数组内存申请释放
int* arr = new int[10];
delete[] arr;
```
